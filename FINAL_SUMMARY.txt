================================================================================
                         TROUBLESHOOTING
================================================================================

Problem: docker-compose command not found
Solution: Install Docker from https://docker.com/products/docker-desktop

Problem: npm install timeout
Solution: npm config set fetch-timeout 120000
         npm install --legacy-peer-deps

Problem: Frontend not loading
Solution: cd frontend && npm install && npm run dev

Problem: Backend database error
Solution: docker-compose down -v && docker-compose up --build

Problem: GROQ_API_KEY not set
Solution: Get key from https://console.groq.com
         Add to backend/.env
         Restart: docker-compose restart backend

Problem: Port already in use
Solution: lsof -i :8000  (find process)
         kill -9 <PID>  (kill it)
