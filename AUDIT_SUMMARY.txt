================================================================================
CRITICAL ISSUES (P0 - FIX IMMEDIATELY)
================================================================================

1. MISSING FORM LABELS
   - Form inputs not associated with labels (no htmlFor/id)
   - Screen readers cannot connect input to label
   - Affects: Login.tsx, DocumentUpload.tsx, Search.tsx
   - Impact: Blocks users with screen readers
   - Fix: Add id to inputs, htmlFor to labels

2. ICONS NOT ACCESSIBLE
   - Icons rendered without aria-hidden or aria-label
   - Screen readers announce "image" instead of meaning
   - Affects: All icon usage throughout app
   - Impact: Screen reader users confused
   - Fix: Add aria-hidden="true" for decorative, aria-label for functional

3. NO FOCUS INDICATORS
   - Buttons have no :focus-visible styling
   - Keyboard users can't see which element is focused
   - Affects: All interactive elements
   - Impact: Keyboard navigation impossible
   - Fix: Add outline/ring to :focus-visible in CSS

RECOMMENDATION: Run `/impeccable harden` to fix all P0 issues

================================================================================
MAJOR ISSUES (P1 - FIX BEFORE RELEASE)
================================================================================

4. TOUCH TARGETS TOO SMALL (32px instead of 44px)
   - Small buttons and icons hard to tap on mobile
   - Affects: All button sizes, icon targets
   - Impact: High error rate on mobile
   - Fix: Increase button padding, add min-h/min-w-[44px]

5. HARD-CODED COLORS (40+ instances)
   - Tailwind colors used instead of CSS tokens
   - Design system tokens defined but not enforced
   - Affects: All components with colors
   - Impact: Impossible to theme, maintain, or switch to dark mode
   - Fix: Map Tailwind to CSS variables, use token-based utilities

6. FORM VALIDATION NO VISUAL FEEDBACK
   - Invalid inputs not highlighted
   - Error messages shown but inputs don't change
   - Affects: All form pages
   - Impact: Users don't know which field has error
   - Fix: Add border-error class, aria-invalid attribute

7. ANIMATION PERFORMANCE ISSUES
   - Spin animation may drop frames on low-end mobile
   - No GPU acceleration hints
   - Affects: LoadingSpinner, animated transitions
   - Impact: Janky UX on older devices
   - Fix: Add will-change, transform: translateZ(0), steps() timing

8. MISSING PREFERS-REDUCED-MOTION SUPPORT
   - Animations play despite user preference
   - No media query for @media (prefers-reduced-motion: reduce)
   - Affects: All animations in app
   - Impact: Users with vestibular disorders get motion sickness
   - Fix: Disable animations when prefers-reduced-motion enabled
