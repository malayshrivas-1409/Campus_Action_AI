## Quick Start

### Prerequisites
1. **Running API Server**
   ```bash
   cd backend
   python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
   ```

2. **Database Setup**
   ```bash
   # Ensure PostgreSQL is running with pgvector extension
   psql postgres -c "CREATE EXTENSION IF NOT EXISTS vector;"
   ```

3. **Environment Config**
   - Verify `GROQ_API_KEY` set in `backend/.env` ✅
   - Verify `DATABASE_URL` configured ✅

4. **Postman Setup**
   ```bash
   # Install Postman or use web version
   # Import collection: File > Import > .postman.json
   ```

## Recommended Test Sequence

### Phase 1: Verify API is Running
**Duration**: ~2 minutes

```
1. GET /health
   Expected: 200 OK
   Response: { "status": "healthy", "message": "..." }

2. GET /
   Expected: 200 OK
   Response: API info + version
```

**If either fails**: API not running or not accessible at `http://localhost:8000`

---

### Phase 2: Authentication Flow
**Duration**: ~3 minutes  
**Critical**: Save `access_token` from login response to use in subsequent requests

```
1. POST /api/v1/auth/signup
   Body:
   {
     "email": "test.student@example.com",
     "name": "Test Student",
     "password": "SecurePassword123!",
     "role": "student"
   }
   Expected: 200 OK
   Extract: access_token → Set as {{access_token}} in Postman environment
   
2. POST /api/v1/auth/login
   Body:
   {
     "email": "test.student@example.com",
     "password": "SecurePassword123!"
   }
   Expected: 200 OK
   Extract: New access_token (should match from signup)

3. GET /api/v1/auth/me
   Header: Authorization: Bearer {{access_token}}
   Expected: 200 OK
   Response: Current user info
   Extract: user_id → Set as {{user_id}} in environment
```

**If any fails**: Check credentials, JWT configuration

---

### Phase 3: Student Profile
**Duration**: ~2 minutes  
**Dependencies**: Must complete Phase 2 first

```
1. POST /api/v1/students/profile

3. PUT /api/v1/students/me
```

### Phase 4: Document Upload & Management
**Duration**: ~5 minutes  
**Dependencies**: Need working filesystem + PDF processing

```
1. POST /api/v1/documents/upload
   Header: Authorization: Bearer {{access_token}}
   Body: form-data
     - title: "Placement Policy 2024"
     - document_type: "placement"
     - file: [select a test PDF file]
   Expected: 200 OK
   Response: {
     "success": true,
     "document_id": "...",
     "version_id": "...",
     "chunks_created": N
   }
   Extract: document_id → Set as {{document_id}}

2. GET /api/v1/documents
   Header: Authorization: Bearer {{access_token}}
   Query: skip=0, limit=20
   Expected: 200 OK
   Verify: Your uploaded document appears in list

3. GET /api/v1/documents/{document_id}
   Header: Authorization: Bearer {{access_token}}
   Expected: 200 OK
   Verify: Document details match upload

4. DELETE /api/v1/documents/{document_id}
   Header: Authorization: Bearer {{access_token}}
   Expected: 200 OK
```

**Common Failures**:
- ⚠️ File too large (> 50MB) → Upload smaller PDF
- ⚠️ Invalid file format → Must be .pdf
- ⚠️ PDF parsing error → Check PDF is not corrupted
- ⚠️ pgvector issue → Verify PostgreSQL + extension

### Phase 5: Embedding & Search
**Duration**: ~10 minutes  
**Dependencies**: Documents uploaded with chunks created

```
1. GET /api/v1/search/info
   Header: Authorization: Bearer {{access_token}}
   Expected: 200 OK
   Response: {
     "model_name": "BAAI/bge-small-en-v1.5",
     "embedding_dimension": 384,
     "service_status": "ready"
   }

2. POST /api/v1/embeddings/generate-all
   Header: Authorization: Bearer {{access_token}}
   Expected: 200 OK
   Response: { "success": true, "total_processed": N }
   Note: First time will download embedding model (~200MB)

3. POST /api/v1/search/vector
   Header: Authorization: Bearer {{access_token}}
   Body:
   {
     "query": "placement eligibility criteria",
     "limit": 10,
     "threshold": 0.5
   }
   Expected: 200 OK
   Response: Array of similar chunks with scores
   Note: Will be empty if embeddings not generated

4. POST /api/v1/search/keyword
   Header: Authorization: Bearer {{access_token}}
   Body:
   {
     "query": "CGPA requirement",
     "limit": 10
   }
   Expected: 200 OK
   Response: Array of keyword-matched chunks
```

**Common Failures**:
- ⚠️ Empty search results → Documents not uploaded or embeddings not generated
- ⚠️ pgvector error → Dimension mismatch, check embedding model
- ❌ Timeout on embeddings → Model download in progress, wait 2-3 minutes

### Phase 6: RAG & LLM
**Duration**: ~8 minutes  
**Dependencies**: Documents uploaded + embeddings generated + GROQ_API_KEY configured

```
1. GET /api/v1/rag/status
   Header: Authorization: Bearer {{access_token}}
   Expected: 200 OK
   Response: {
     "status": "operational",
     "llm_configured": true,
     "llm_model": "openai/gpt-oss-20b",
     "embeddings_available": true
   }
   Note: If `llm_configured` is false, GROQ_API_KEY not set

2. POST /api/v1/rag/retrieve
   Header: Authorization: Bearer {{access_token}}
   Body:
   {
     "query": "placement requirements",
     "top_k": 10,
     "vector_weight": 0.7,
     "keyword_weight": 0.3
   }
   Expected: 200 OK
   Response: Array of retrieved chunks

3. POST /api/v1/rag/query
   Header: Authorization: Bearer {{access_token}}
   Body:
   {
     "query": "What are the eligibility criteria for placement?",
     "top_k": 10
   }
   Expected: 200 OK
   Response: {
     "response": "LLM-generated answer with context",
     "sources": [...],
     "chunks_retrieved": N
   }
   Note: Response time ~3-5 seconds (includes LLM inference)
```

**Common Failures**:
- ❌ 503 Service Unavailable → GROQ_API_KEY not set
- ⚠️ Timeout → LLM taking too long, retry
- ⚠️ Poor quality response → Not enough documents or wrong documents

## Common Issues & Fixes

### ❌ "Connection refused" (localhost:8000)
**Cause**: API server not running  
**Fix**:
```bash
cd backend
python -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

### ❌ "401 Unauthorized"
**Cause**: Invalid or missing Bearer token  
**Fix**: 
1. Run login request again
2. Copy `access_token` from response
3. Update `{{access_token}}` environment variable
4. Retry request

### ❌ "403 Forbidden"
**Cause**: User doesn't own resource (document, conversation, etc.)  
**Fix**: 
- Make sure you're using your own user's token
- Don't try to access other users' data

### ❌ "404 Not Found"
**Cause**: Resource doesn't exist or wrong URL  
**Fix**:
1. Check endpoint path spelling
2. Verify resource ID is correct (use list endpoints first)
3. Make sure resource was created successfully

### ⚠️ Vector search returns empty
**Cause**: Embeddings not generated or documents empty  
**Fix**:
1. Run `/api/v1/embeddings/generate-all` first
2. Verify documents have content (get document details)
3. Check model download completed in logs

### ⚠️ Chat returns 503 Service Unavailable
**Cause**: GROQ_API_KEY not configured  
**Fix**:
```bash
# In backend/.env, add:
GROQ_API_KEY=your-key-from-console.groq.com

# Restart API server
```

### ⚠️ Very slow responses (>10s)
**Cause**: 
- First embedding model download
- LLM inference time
- Database slow queries
  
**Fix**:
1. First embedding download: Wait, then cache at ~/.cache/huggingface
2. LLM slowness: Normal, can take 3-5s for inference
3. Database: Check PostgreSQL is running, not under load

```bash
  -e postman-env.json \
  --reporters cli,json \
```
